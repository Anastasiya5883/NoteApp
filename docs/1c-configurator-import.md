# Загрузка структуры конфигурации 1С

1. В Конфигураторе выполните выгрузку конфигурации в файлы XML.
2. Упакуйте каталог выгрузки в ZIP-архив.
3. Откройте личный кабинет и вкладку «Информация из локального конфигуратора».
4. Загрузите ZIP. На вкладке появятся дата загрузки и количество объектов и реквизитов.
5. После изменения конфигурации загрузите новый архив — он заменит предыдущий.

При анализе требований локальная структура считается основным источником. Если она не загружена, используется встроенный неполный справочник 1С:ERP 2.6.1.16, а результат помечается предупреждением.

Ограничения: принимается только ZIP со стандартной XML-выгрузкой Конфигуратора; исполняемый код 1С не загружается и не анализируется.
