# Разделение промта и содержимого файла

## Цель

После загрузки файла большое текстовое поле должно содержать только пользовательский промт. Извлечённый текст файла не должен отображаться или копироваться в это поле, но должен оставаться источником данных для анализа и истории.

## Поведение интерфейса

- Текстовое поле хранит только промт пользователя.
- Загрузка нового файла не изменяет уже введённый промт.
- Под полем по-прежнему отображается имя текущего файла.
- Если файл не загружен, содержимое текстового поля анализируется как самостоятельное ТЗ для сохранения существующего сценария ручного ввода.
- Кнопка анализа доступна, если есть непустой промт или успешно загруженный файл.

## Поток данных

Приложение хранит три независимых значения:

- `prompt` — видимый текст из поля;
- `fileName` — имя загруженного файла;
- `fileContent` — извлечённый текст файла, не отображаемый в поле.

При наличии файла анализатор получает `fileContent`. Без файла анализатор получает `prompt`. Для файлового анализа промт преобразуется в ограниченные локальные настройки анализа, но не добавляется к исходному тексту ТЗ.

## Поддерживаемая команда промта

На первом этапе поддерживается команда «только критические противоречия» и близкая формулировка с теми же словами без учёта регистра. Она фильтрует найденные противоречия до уровня `critical`, не меняя исходный текст файла и остальные этапы анализа.

Пустой промт или промт без распознанной команды запускает полный анализ. Произвольные инструкции не интерпретируются как команды и не вызывают ошибку.

## История

Для загруженного файла сохраняются имя файла, полный исходный `fileContent` и итоговый результат анализа после применения команды промта. Сам промт в текущую структуру истории не добавляется.

Ручной ввод без файла сохраняется только по прежним правилам приложения; это изменение не расширяет историю анализов без имени файла.

## Ошибки и сброс состояния

- Ошибка чтения файла не должна заменять текущий промт или ранее успешно загруженный файл.
- Загрузка другого успешного файла заменяет `fileName` и `fileContent`, сохраняя промт.
- Сброс анализа очищает промт, имя файла и скрытое содержимое файла.

## Проверка

Автоматические тесты должны подтверждать:

- загрузка файла не меняет промт;
- анализ использует содержимое файла, а не видимый промт;
- команда «только критические противоречия» фильтрует некритические противоречия;
- пустой или неизвестный промт сохраняет полный результат;
- история получает исходный текст загруженного файла;
- сброс очищает оба независимых источника текста.
