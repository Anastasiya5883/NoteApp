# NoteApp
NoteApp - приложение, разрабатываемое в рамках учебного курса "Технологии разработки ПО"

## Запуск веб-приложения в Docker

Требуется Docker с поддержкой Compose.

```powershell
docker compose up --build -d
```

После запуска приложение доступно по адресу <http://localhost:3001>.

В образ включена текущая база SQLite с существующими пользователями и историей.
При первом запуске Docker копирует её в постоянный том `app-data`. Последующие
изменения сохраняются при перезапуске и пересборке контейнера.

Просмотр состояния и журналов:

```powershell
docker compose ps
docker compose logs -f app
```

Остановка приложения без удаления данных:

```powershell
docker compose down
```

Чтобы удалить сохранённые в Docker данные и при следующем запуске снова начать
с базы, встроенной в образ, выполните `docker compose down -v`. Эта команда
безвозвратно удаляет изменения, сделанные после первого запуска контейнера.
